# LWNet (little W-Net)

LWNet shows that retinal vessel segmentation does not need a large network. Its W-Net — two small
U-Nets chained together — has roughly 70,000 parameters, orders of magnitude fewer than typical
segmentation models, and its authors report that it matches or beats far more complicated methods.

Two relatives are catalogued separately: [Big W-Net](big-wnet.md), the artery-vein model from the
same repository, and [AutoMorph's disc-and-cup model](automorph-disc-cup.md), which is this
architecture retrained by other authors for a task this paper does not address.

## 1. Code reference

- **Repository:** https://github.com/agaldran/lwnet
- **Version described here:** commit `ce72ddab` (2024-01-16). No tags or releases.
- **Most recent commit:** 2024-01
- **Training code included:** Yes, in this repository — `train_cyclical.py`, plus
  `get_public_data.py`, which downloads seven of the paper's ten datasets and writes the train,
  validation and test split CSVs. Of the models in this catalogue this is the one whose results are
  most nearly reproducible from the repository alone.
- **Language and how it runs:** Python with PyTorch, in a conda environment from
  `environment.txt`. `predict_one_image.py` and `predict_one_image_av.py` run a single photograph;
  `generate_results.py` and `analyze_results.py` run and score whole datasets.

## 3. Major publications by the authors

- Galdran A, Anjos A, Dolz J, Chakor H, Lombaert H, Ben Ayed I. *The Little W-Net That Could:
  State-of-the-Art Retinal Vessel Segmentation with Minimalistic Models.* 2020.
  [arXiv:2009.01907](https://arxiv.org/abs/2009.01907)

## 4. What it produces

- **Purpose:** `vessels`
- **Output classes:** one class — blood vessel against background. This model does not segment the
  optic disc; the pipelines that use the architecture for disc and cup retrained it themselves.
- **Input expected:** a colour-fundus photograph; the repository prepares each dataset to its own
  resolution.
- **Preprocessing in the published code:** per-dataset preparation by `get_public_data.py`, which
  also produces field-of-view masks and, for DRIVE, the Zone B masks used to score artery-vein
  performance near the optic disc.

## 5. Architecture

- **Family:** W-Net — two chained U-Nets, the second refining the first.
- **Parameters:** approximately 70,000, as stated by the authors.
- **Single model or ensemble:** a single model per dataset configuration.

## 6. Training data

| Dataset | Role | Annotations by | Split stated |
| --- | --- | --- | --- |
| DRIVE | Training | The dataset's own authors | Yes, split CSVs generated by `get_public_data.py` |
| CHASE-DB | Training | The dataset's own authors | Yes |
| HRF | Training | The dataset's own authors | Yes |
| Seven further public datasets | Evaluation, including cross-dataset experiments | Their own authors | Yes, test CSVs provided |

DRIVE, CHASE-DB and HRF cannot be used to benchmark the published vessel weights. The repository's
cross-dataset experiments are the useful precedent here: they measure the model on datasets it was
not trained on, which is the only comparison that generalises.

## 7. Weights

- **Publicly available:** Yes, committed in the repository and small enough for that to be
  practical.
- **Download URLs:**
  - https://github.com/agaldran/lwnet/tree/main/experiments/wnet_drive — `model_checkpoint.pth`,
    trained on DRIVE
  - Pre-generated segmentations for the paper's datasets, if only the outputs are needed:
    https://gitlab.com/agaldran/shared_results/-/raw/master/pre_generated_results.zip
- **Format and size:** PyTorch `model_checkpoint.pth`, about 900 KB, with a `config.cfg` and
  validation metrics beside each one.
- **Files in an ensemble:** one per experiment folder.

## 8. Performance as reported by the authors

The paper reports state-of-the-art or comparable vessel-segmentation performance against
substantially larger models, and `analyze_results.py` reproduces those measurements. Per-dataset
numbers are in the paper and are not restated here; the claim to record is the authors': that a
70,000-parameter model suffices.

## 11. Notes

- **The architecture travels further than these weights.** Three pipelines use the W-Net
  architecture for optic disc and cup after retraining it, so this paper's reported performance says
  nothing about the disc masks they produce. That model is [automorph-disc-cup.md](automorph-disc-cup.md).
- Small enough to train and run on modest hardware, including CPU, which makes it a sensible
  baseline to beat before reaching for a larger model.
- The repository also covers pseudo-label training and cross-dataset evaluation, both useful when
  judging behaviour on an unfamiliar camera.
