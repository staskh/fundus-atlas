# Benchmarks

What this repository measured against what experts annotated, on the same images and on the same terms. Each section is one benchmark; the pages it links to say how it was run and what came out, and `results/` holds the score of every photograph behind every number. This file is generated by the runs.

**Read a row, not a column.** A result marked `in-sample` or `unknown` is not comparable with one marked `out-of-sample`, and a model agreeing with another model is not evidence that either agrees with an expert.
