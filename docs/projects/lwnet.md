# LWNet (The Little W-Net That Could)

LWNet segments blood vessels, and separately arteries against veins, using a deliberately tiny
network: a W-Net of roughly 70,000 parameters — two chained U-Nets, orders of magnitude smaller than
typical segmentation models — which its authors show matches or beats far more complicated methods.
Its practical importance to this atlas is second-hand: it supplies the optic disc and cup
segmentation inside AutoMorph, AutoMorphalyzer and AutoMorphClass, so its behaviour is baked into
three other entries here.

It is a model with a thorough evaluation harness, not a biomarker pipeline: it outputs masks, not
measurements (see the scope note in section 9).

## 1. Code reference

- **Repository:** https://github.com/agaldran/lwnet
- **Version described here:** commit `ce72ddab` (2024-01-16). No tags or releases are published.
- **Most recent commit:** 2024-01
- **Training code included:** **Yes** — `train_cyclical.py`, plus `get_public_data.py`, which
  downloads and prepares seven of the ten datasets used in the paper and writes the train, validation
  and test split CSVs. Of the entries in this catalogue this is the one that most fully supports
  reproducing its own results.
- **Language and how it runs:** Python with PyTorch, via a conda environment
  (`conda create --name lwnet --file environment.txt`). `predict_one_image.py` and
  `predict_one_image_av.py` run a single image; `generate_results.py` and `generate_av_results.py`
  run whole datasets; `analyze_results.py` computes performance.

## 5. Models introduced here

### 5.1 W-Net (vessels) and Big W-Net (artery/vein)

- **Training data:** DRIVE, CHASE-DB and HRF for vessel segmentation; DRIVE and HRF for
  artery/vein segmentation. The paper uses ten datasets in total, seven of them public and fetched
  automatically by `get_public_data.py`; the remaining datasets are evaluation-only. Split CSVs are
  generated by that script rather than left to the reader, and the repository also prepares DRIVE's
  Zone B masks, used to evaluate artery/vein performance in the region around the optic disc.
- **Weights publicly available:** Yes — committed in the repository, and small enough that this is
  practical (under 1 MB per checkpoint).
- **Download URLs:**
  - Vessels, DRIVE: https://github.com/agaldran/lwnet/tree/main/experiments/wnet_drive
    (`model_checkpoint.pth`, about 900 KB, with its `config.cfg` and validation metrics beside it)
  - Artery/vein, DRIVE: https://github.com/agaldran/lwnet/tree/main/experiments/big_wnet_drive_av
  - Artery/vein, HRF at 1024 px: https://github.com/agaldran/lwnet/tree/main/experiments/big_wnet_hrf_av_1024
  - Pre-generated segmentation results for the paper's datasets, if you only want the outputs:
    https://gitlab.com/agaldran/shared_results/-/raw/master/pre_generated_results.zip
- **Training code:** Yes, in this repository.

## 6. Biomarkers computed

Not applicable — LWNet produces segmentation masks and segmentation metrics, not vascular
biomarkers. Its quantitative outputs are performance measures against reference annotations
(computed by `analyze_results.py`), which are a measure of the model rather than of the eye.

Downstream, the biomarkers most often derived from an LWNet output are AutoMorph's, computed from
its optic disc and cup masks — see [automorph.md](automorph.md) section 6.

## 7. Examples and notebooks

- `predict_one_image.py` — start here; a single fundus photograph in, a vessel mask out, with no
  dataset preparation needed. `predict_one_image_av.py` does the same for arteries and veins.
- `get_public_data.py` followed by `generate_results.py` and `analyze_results.py` — the path to
  reproducing the paper's numbers, and the reason this repository is a good reference for how a
  segmentation evaluation should be laid out.

## 9. Notes

- **Scope note.** LWNet is a segmentation model, not a pipeline that returns numbers about an eye,
  so it does not meet this atlas's definition of a project. It is catalogued here because three
  other projects depend on it and because a reader tracing where their disc segmentation came from
  will look for it by name. When the segmentation-model catalogue exists, this page's technical
  detail belongs there.
- **Small is the point.** At roughly 70k parameters it trains and runs on modest hardware, including
  CPU, which is unusual among the models in this catalogue and makes it a sensible baseline to beat
  before reaching for anything larger.
- The repository also covers training with pseudo-labels and cross-dataset experiments, both useful
  when judging how a model will behave on a camera it has not seen.
