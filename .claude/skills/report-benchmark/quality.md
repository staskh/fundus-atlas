# The quality benchmark's two documents

Load this beside `SKILL.md` when changing `docs/benchmarks/quality-docs.md` or
`docs/benchmarks/quality-results.md`.

## 1. What `quality-docs.md` must explain that no other benchmark has

Generated by the run, so these belong in the generator:

- **The three kinds of reference** — `published`, `derived`, `assumed` — with the derivation spelled
  out for each dataset that uses one, and the warning that an `assumed` reference contains no bad
  photographs at all.
- **The black canvas share per dataset**: how much of the square the store built is not photograph.
  A quality model judges the square it is handed.
- **Every column of the evidence**, including the four a model may leave absent — `verdict`,
  `good`, `usable`, `bad` — and why: a scalar model has no classes to report and none are invented
  for it.
- **`carried_by_its_pipeline`**, which is not the model's verdict but its project's decision, with
  each project's rule quoted.

## 2. What `quality-results.md` says, section by section

Written from `notebooks/quality.ipynb`, following `SKILL.md` §4:

1. **Contents.**
2. **Summary — every dataset pooled**, one row per model: photographs, coverage, accuracy, Cohen's
   κ, and the contamination mark. Nothing else. Accuracy and κ are read together and the page says
   why: accuracy flatters a model on a dataset where one class dominates.
3. **Which mistake each model makes.** The confusion, pooled: the share of worth-measuring
   photographs kept against the share of the rest discarded. This is the section that distinguishes
   two models with the same accuracy, and it comes before any per-dataset detail because it is the
   thing a reader most needs and least expects.
4. **Dataset by dataset**, then by subset and split — where a dataset's splits carry different
   marks, the breakdown is required.
5. **What the analysis found**, from the notebook: which defect each model reacts to (FIVES
   publishes its three component scores), where models agree because they share training labels,
   how models do where the readers themselves disagreed, and how much of a curated dataset each
   would discard.
6. **Which model to use**, per `SKILL.md` §5 — with the question named, the runner-up where it is
   close, and the caveats that would change the answer.
7. **What these numbers do not say.**

## 3. The conclusions this benchmark has to state plainly

- **The models disagree about which mistake to make, not about how often.** Two graders with the
  same accuracy can sit at opposite ends of keeping-versus-discarding, and a study feels that
  difference as either a lost sample or unusable measurements.
- **A threshold set on other data does not transfer.** A model can rank photographs almost perfectly
  and still gate badly; say which it is doing.
- **Models fitted on the same labels agree with each other**, and that agreement is not evidence.
- **Against an assumed reference, a number is a keep-rate, not an accuracy.**
- **Where the readers of a dataset agree with each other less than a model agrees with their
  consensus**, the benchmark is measuring reproduction of a committee. `notebooks/quality-humans.ipynb`
  is where that ceiling is measured, and the results page cites it rather than restating it.
